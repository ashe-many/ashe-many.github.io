# Image-token compression for vision-language models

Pipeline page: https://ashe-many.github.io

Experiments with Qwen3-VL-4B (4-bit, MLX) on an 8 GB Apple M1: image-token dropping, drop-aware LoRA fine-tuning,
learned compressor experts with a router, question-aware experts, and tests on POPE, GQA and TextVQA.
Click a box on the page for the details and results. Sources and dataset licenses are listed at the end of the page.
